① 研究方向

核心命题

当 drafter 与 verifier 共享硬件资源（compute time, memory bandwidth, attention budget）时，drafter 的有效预算 Bi 成为 verifier lookahead {kj} 的隐函数 Bi = φi({kj})。 这一耦合使得 per-client 服务曲线 μ(k) 非单调，存在内部最优 k*。

FOC: αk* · log(1/α) · p_hit(k*) = q'(k*) · (1 − αk*)
大 TV 渐近: k* ≈ r · log TV / log(1/α) + O(log log TV)

三段叙事弧

  • 共享资源耦合 · drafter 预算变成 verifier 选择的隐函数
  • 非单调服务曲线 · 单客户端服务函数单峰，存在 k*
  • 多客户端分配结构 · KKT 暴露正外部性，scheduler 出现结构性不一致
